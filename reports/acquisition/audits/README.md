# Acquisition Audits

This folder stores lightweight lead audits used to prepare personalized outreach.

Each audit must be based on public storefront evidence and should take 5-10 minutes. The goal is to identify one commercial problem that WhaleLeap can credibly help verify or fix.

Do not store credentials, private contact information, guessed revenue, guessed traffic, guessed conversion rate, or guessed ad spend.

Use cautious language for anything that cannot be directly confirmed from public evidence:

- possible
- potential
- worth verifying

Do not turn these audits into full SEO reports or broad technical audits.
