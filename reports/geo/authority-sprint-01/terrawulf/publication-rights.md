# Terrawulf Publication Rights

## Current Authorization

**FULL PROJECT PUBLICATION ALLOWED**

Client-approved public disclosure was recorded on 2026-10-01. Publication remains subject to minimum-necessary disclosure.

Possession of project files is not publication permission.

## A. Public

| Evidence | Allowed Now | Boundary |
|---|---|---|
| Live storefront URLs | Link to and describe directly observable storefront facts | Cannot attribute implementation to WhaleLeap without authorization. |
| Public product/collection/home content | Record factual current observations internally | Republishing screenshots, logos or product media still requires rights review. |

## B. Internal

- Signed contract and identities.
- Theme repositories, Liquid, JSON templates, CSS and JavaScript.
- Git history and commit metadata.
- Shopify store/theme IDs and Admin URLs.
- Theme Check, deployment and remote-readback records.
- Operator guide and launch summary.
- Admin, market, shipping, payment or policy configuration evidence.

These items are not authorized for public release.

## C. Potentially Publishable

Only after ownership and client permission are documented:

- Final Figma frame excerpts.
- Redacted Theme Editor screenshots.
- Small, non-sensitive code snippets.
- Before/after implementation screenshots.
- Architecture diagrams derived from the real implementation.
- A project description limited to verified responsibilities.

## D. Requires Authorization

- Terrawulf name as a WhaleLeap case study.
- Terrawulf logo and branded assets.
- Live-store screenshots reused on WhaleLeap properties.
- Figma screenshots or source frames.
- Theme Editor/Admin screenshots.
- Code excerpts or repository history.
- Contract wording or personal identities.
- Analytics, sales, conversion, advertising or customer data.
- Performance evidence and business results.
- Public WhaleLeap attribution and individual/team credits.

## Excluded From Publication

- Bank information, contract value and signatures.
- OAuth tokens, credentials, API keys and customer Admin accounts.
- Private contact details and unrelated internal commercial data.
- Complete theme source, complete contract text and private customer data.

## Gate

**Case Study Publication: APPROVED AND PUBLISHED**

The public case study uses approved project materials, small derived code/architecture evidence and public storefront captures. This authorization does not create permission to publish excluded sensitive material or to make unverified performance claims.
